# Human Annotation Tool

This folder contains everything needed to run a human annotation study for evaluating the LangDMTA drug discovery agentic system. Human annotations are compared against LLM judge scores to measure human-LLM alignment.

## LangDMTA

LangDMTA is a LLM-based agentic system for drug discovery. The agent has a multi-agent architecture, with a supervisor agent delegating the work to four sub-agents:

- Design - an agent that can generate novel compounds and score compounds
- Synthesis - an agent that can assist in the planning of the chemical synthesis of compounds
- Analyzer - an agent that can analyze an output file in CSV format in order to compute statistics or make plots
- Utility - an agent that assists in miscellaneous tasks such as converting common names of compounds to chemical structures

The agentic system is a tool-based system which uses tools such as Molformer - for design tasks and AiZynthFinder and PrecedentFinder - for synthesis tasks.
The user can ask the agentic systems to complete tasks such as generating molecules similar to a reference molecule, provide synthesis routes for a given molecule, convert molecule names to SMILES and get different property values for molecules. 

### Note:
- Default settings are always used when running the tools
- Referring to Similarity, it is always the same Tanimoto Similarity that is considered
- When asking to generate analogues, this is interpreted as generating molecules that are similar to the reference
- Neither of the tools provide any reasoning about the chemicals or chemical reactions - if included in the output, this has been added by the LLM agents
- For molecular generation tasks - the result should be saved to a CSV file and the path should be provided in the output

## Environment Setup

The annotation tool requires Python >= 3.9 with `flask`, `pandas`, and `markdown`.

**Create a fresh environment**

```bash
conda create -n annotation python=3.11 -y
conda activate annotation
pip install flask pandas markdown
```

## Running the Web App

```bash
cd evaluation/langdmta_eval/human_annotation

# Default
python human_annotation_app.py --csv annotator_sheet.csv
```

This will automatically open a browser at `http://localhost:5000`. Use `--port <N>` to change the port.

**Other options:**

```bash
python human_annotation_app.py --help

# Custom port
python human_annotation_app.py --csv annotator_sheet.csv --port 8080

# Don't auto-open browser
python human_annotation_app.py --csv annotator_sheet.csv --no-browser

# Browse completed annotations without saving
python human_annotation_app.py --csv annotator_sheet_annotated.csv --read-only
```

**File handling:**
- The original CSV is **never modified**
- A `*_in_progress.csv` working copy is created and updated on every save
- If you restart the app, it automatically resumes from the working copy
- A `*_annotated.csv` final export is created when all cases are completed


## Annotation Guide

### What You Will See

For each case, you will be shown:

- **Question** - The original task/question posed to the drug discovery agent
- **Agent Output** - The response generated by the agentic system
- **Evaluation Context** - Additional context describing what is expected from the output (read this carefully)
- **Tool Calls (actual)** - Which tools the agent called
- **Expected Tool Calls** - The ideal sequence of tools for this task
- **Accepted Tool Calls** - Alternative acceptable tool sequences

### Scoring Metrics

Score each case on the following 4 metrics:

#### 1. Completeness

How complete is the output in covering all required information? This metric evaluates **recall**: of the information that should be present, how much is actually there? See the EVALUATION CONTEXT for information about the expected output. **Do not penalize for off-topic content — that is assessed by Relevancy.**

| Score | Value | Meaning |
|-------|-------|---------|
| INCOMPLETE | 0.0 | Fails to provide most of the required information |
| PARTIALLY COMPLETE | 0.5 | Addresses the main point but missing some required information or key details |
| COMPLETE | 1.0 | All key information, results, and details required by the task are present |

#### 2. Relevancy

How relevant is the output content to the task? This metric evaluates **precision**: of the information present, is it pertinent to the request? **Do not penalize for missing information — that is assessed by Completeness.**

| Score | Value | Meaning |
|-------|-------|---------|
| NOT RELEVANT | 0.0 | Output is largely off-topic or addresses a different question |
| PARTIALLY RELEVANT | 0.5 | Addresses the task but includes noticeable irrelevant or off-topic content |
| RELEVANT | 1.0 | All content directly addresses the task without irrelevant information |

#### 3. Structural Clarity

How well-structured and easy to parse is the output? This metric evaluates **presentation only**: formatting, organization, logical flow, and readability. Do not evaluate whether the content is accurate, on-topic, or complete.

| Score | Value | Meaning |
|-------|-------|---------|
| UNCLEAR | 0.0 | Poorly organized or formatted in a way that significantly hinders comprehension |
| PARTIALLY CLEAR | 0.5 | Some structural issues but still broadly understandable |
| CLEAR | 1.0 | Well-organized with appropriate structure and logical flow |

#### 4. Scope Adherence

Does the agent operate within its intended scope and use its capabilities appropriately?

| Score | Value | Meaning |
|-------|-------|---------|
| BELOW TARGET | 0.0 | Fails to use available tools, hallucinates instead of calling tools, refuses reasonable requests, or asks for unnecessary clarification |
| ON TARGET| 0.5 | Uses tools correctly, addresses exactly what was asked, neither overreaches nor under-delivers |
| ABOVE TARGET | 1.0 | Goes beyond task scope, adds reasoning about the chemistry / chemicals, makes unsolicited tool calls, or provides unrequested actions |

#### Justification (optional)

Optionally provide a **brief** free-text justification (1-2 sentences) for your rating. Focus on anything that stands out, where surprising or where you were uncertain about the rating. This field is not required to submit your scores.

---

### Tips

- Always read the **Evaluation Context** before scoring - it defines what the expected outcome is for each case
- You can revisit and change any previous annotation at any time
- Your progress is auto-saved so you won't lose work
- The samples will include both successful and unsuccessful requests - try to judge both cases as fairly as possible.

## Extracting a New Annotation Sample

To generate a new annotation sample from LLM evaluation results:

```bash
cd evaluation/langdmta_eval/human_annotation

# Single result file
python extract_annotation_sample.py \
  /path/to/evaluation_results.json \
  -n 60 -o annotation_sample.csv

# Multiple result files
python extract_annotation_sample.py \
  /path/to/trial_1.json /path/to/trial_2.json /path/to/trial_3.json \
  -n 60 --complex-ratio 0.7 --seed 42 -o annotation_sample.csv

# Include duplicate questions for self-consistency checks
python extract_annotation_sample.py \
  /path/to/evaluation_results.json \
  -n 60 --n-duplicates 5 -o annotation_sample.csv
```

This produces two files:
- `annotation_sample.csv` - Full sample with LLM scores (for alignment analysis)
- `annotation_sample_annotator_sheet.csv` - Clean sheet for annotators (no LLM scores)

**Sampling parameters:**

| Flag | Default | Description |
|------|---------|-------------|
| `-n` | 60 | Target number of samples |
| `--complex-ratio` | 0.6 | Fraction from complex multi-tool workflows |
| `--calibration-ratio` | 0.15 | Fraction of easy calibration anchors |
| `--n-duplicates` | 0 | Number of duplicate questions added on top of `-n` for self-consistency checks |
| `--seed` | 10 | Random seed for reproducibility |
